# work-opc 知识库与技能轻量入口

## 来源、背景与确认边界

用户需要在 work-opc 中直接发现并使用企业知识库与 Skills。现有企业工具与下载能力尚未形成可发现的客户端操作入口；知识详情、文档与技能上传管理由 knowledge-web 承担，避免客户端重复建设管理界面。

本需求是已有产品的新迭代，不重新进行产品冷启动访谈。服务对象为使用 work-opc 的企业成员；上传与资源管理者沿用 knowledge-web 已有角色权限。现有业务规模不作为本轮新增容量承诺，性能验收针对资源列表和交互是否阻塞、失败是否可恢复。

2026-10-22，当前用户以“确认”批准联合卡：需求 WORK-RESOURCES-001、三仓必要增量、远程 release 基线、full + loop。身份由本仓 Git 配置读取为 Roger0808 / yj198788@hotmail.com。原话见 ../sources/user-decisions.md。该确认固定产品方向与参与范围；本文件新整理的完整条款为 draft，待独立审查和全文阶段确认。

## 目标与范围

### REQ-001 知识库轻量浏览

work-opc 提供知识库入口，列出当前账号有权访问的知识库，显示名称、简述及所属空间，支持名称搜索和刷新。无资源、未登录、加载失败必须有可区分的提示；不得把错误显示为无资源。客户端不展示完整文档管理界面。

### REQ-002 网页详情与上传

知识库及 Skills 列表提供“查看详情”和“上传”入口。“上传”只需用系统浏览器打开 https://shtokendance.benlai.com，由用户在网页登录、选择空间并上传；不要求新增上传深链或从客户端传递登录态。“查看详情”沿用对应资源链接，指定资源时应定位到正确空间和对象；浏览器未登录时由网页完成登录与鉴权，并支持返回详情目标。上传沿用网页权限，不能因从客户端跳转而扩大权限。浏览器账户与客户端账户不一致时，不得绕过网页登录权限或自动冒用客户端凭据。

客户端不嵌入完整详情编辑器、文件上传表单或技能编辑器。上传后返回客户端，刷新可观察到当前身份有权访问的新资源；正在处理或归档未就绪的条目不得伪装为可使用。

### REQ-003 消息级知识范围

在输入框通过 @ 或“添加知识”选择知识库，显示可移除的范围标签。首版以知识库为粒度。选择仅作用于本条消息；已发送消息保留所用范围，下一条消息不隐式继承。发送失败时保留可重试的消息草稿及其选择。

执行必须约束在所选范围内，不能由模型静默扩大到其他知识库；范围失效、权限变化或不存在时明确失败，不回退为全库检索。未选择时保留现有按需检索行为。知识库单选或多选及上限在 Architecture/Specification 明确，不得影响上述范围约束。

### REQ-004 知识引用可追溯

使用企业知识生成的回答保留来源引用，用户可打开 knowledge-web 查看对应来源。无检索结果应明确说明，不能伪造引用；引用目标无权限、已删除或网页不可达时，必须给出可理解的失败结果。客户端保留必要的引用标识与标题，不建设完整知识详情页。

### REQ-005 企业 Skills 轻量浏览

提供企业技能和已安装视图，支持名称搜索、刷新，显示名称、简介、来源与安装状态。企业技能列表面向当前可见的上传目录，不能只显示经过另一次人工发布的旧 release。上传者完成网页上传且原始归档就绪后，使用者刷新即可发现有权访问的技能，不需要再走发布流水线。本轮客户端的列表、下载和安装必须移除对技能 release 发布及 published 状态的前置依赖；不得用后台自动发布 release 代替人工发布来保留这一依赖。归档完整性、内容哈希及更新识别仍需保留，它们不构成发布步骤。

### REQ-006 手动下载与安装

用户点击“下载并安装”才开始安装；浏览目录、登录或刷新不触发新的自动安装。下载安装必须给出进行中、成功和失败的明确反馈，只有归档完整、校验通过且安装成功后才标记可用。安装失败不留下可执行的半成品；重复操作不得产生可见重复安装。

下载是安装到 work-opc 的能力，不等于把任意归档导出给用户。不可通过把企业技能变成个人技能绕过授权；安装操作不授予上传、发布、管理员或其他资源权限。

### REQ-007 会话使用与生命周期

已安装且当前授权有效的技能可通过“在会话中使用”或现有 /skill 入口选用。点击使用仅准备消息，发送后才执行；安装不自动执行。企业与个人同名技能必须可区分，并使用用户所选对象，不能静默覆盖或误调。

提供手动更新、停用和卸载；更新失败保留原可用版本，停用或卸载不误删个人技能。旧版已安装企业技能的保留、识别与升级兼容在 Architecture 明确，不能静默删除。已启动任务与更新/卸载的关系须在 Specification 定义；不能向正在运行的任务混入另一版本。

### REQ-008 身份、权限与异常

列表、下载及使用都受当前身份与资源权限约束。账号/空间切换后不再允许操作旧身份资源；退出登录或授权失效后，企业资源不能靠本地已有文件继续获得企业使用权限。个人能力保持原有行为。

保留原企业授权约束，尤其已有 60 秒撤权目标不得因手动安装而放宽；本轮必须给出真实计时证据，不能沿用旧迭代尚未执行的验证作为 PASS。已加载指令不能被宣称从历史上下文中抹除；后续企业执行与资源访问仍需拦截，具体运行中行为在后续规格明确。

### REQ-009 跨仓交付与兼容

work-opc 为唯一主仓，负责 GUI 与运行时；platform-opc 补齐必要列表与下载适配；knowledge-opc 补齐技能目录归档能力及资源详情定位的必要增量；不为上传入口新增网页深链。服务端变更限制于本轮客户端闭环。按用户 2026-10-22 后续决定，code-opc 不作为本轮兼容约束，也不修改或测试该仓；上一 Loop 未通过验收的技能 release 旧链路允许直接删除，不能再以该调用方为理由保留。各仓真实验证、发布顺序与回滚在后续阶段维护，不以计划代替已实现能力。

## 用户场景

### SCN-001 发现并使用知识

企业成员打开知识库列表，选中一个有权访问的库并带入聊天，发送问题，获得仅来自所选范围的检索结果及可打开的引用。

### SCN-002 网页管理后回到客户端

具备上传权限的用户从客户端打开 knowledge-web，完成知识或技能上传后返回并刷新。新资源按权限可见，处理状态真实；无上传权限者不能借该入口上传。

### SCN-003 安装并使用企业技能

成员浏览企业技能，查看网页详情，回到客户端手动安装，再选用技能发送任务。下载失败可重试，安装成功前不能执行。

### SCN-004 权限或版本变化

用户已选范围或技能后发生撤权、切换账号或资源更新，系统明确阻止不合法使用，不误用其他资源。手动更新失败可继续使用原本仍获授权的旧版本。

## 非目标

### NG-001 不建设客户端管理后台

详情、知识内容管理、技能编辑和上传均在 knowledge-web，保持客户端简单。

### NG-002 不扩展本轮资源粒度与客户端

不做文件/标签选择、ZIP 导出、code-opc 新界面或 MCP @ 调用入口，集中交付 work-opc 两类资源闭环。

### NG-003 不处理无关平台待办

不做云端 Agent 委托、组织自动同步、code 后端门控/审批/WS 问题、历史孤表清理、无关配置清理、SQLite 发布迁移补链及通用查询性能工程。保留 docs/backlog.md 原条目。

## 非功能与工程扩展

### NFR-001 安全（适用）

浏览器跳转不携带客户端 Token、密码或私密连接串；只允许受信的 knowledge-web 地址，资源参数正确编码。验证包括未登录、无权限、跨空间同名资源、账号切换、恶意跳转、归档路径穿越和撤权计时。不扩大上传/发布角色权限。

### NFR-002 恢复与交互（适用）

网络失败不使聊天界面失去响应，资源页能重试；下载中断、校验失败、更新失败和服务端版本不兼容均可见。验证失败注入、重试、更新保留旧版本，以及聊天草稿不丢失。

### NFR-003 测试与属性（适用）

Testing 覆盖上述正常、失败和权限路径。PBT 候选不变量包括所选知识范围不扩大、不同身份资源不串用、重复安装不产生重复可执行记录、归档不逃逸安装根目录。后续记录 Property、case 数、seed 与缩减反例；这里不宣称测试通过。

### NFR-004 兼容性（适用）

回归现有个人 Skills、企业技能优先级、聊天附件、未选范围检索及登录回跳。本轮使用链路不依赖技能 release。删除上一 Loop 的技能 release 发布、协调和分发旧链路；旧表与归档按明确的迁移及回滚设计清理，不以 code-opc 为理由保留兼容；已安装目录兼容必须有证据；是否涉及数据模型变更由 Architecture 基于实际方案判断。

## 成功标准

### ACC-001 资源可发现（REQ-001/005/008）

授权测试账号能找到其知识库与上传技能；无权资源不泄露，网络错误与空列表可区分，账号切换后不残留可操作资源。

### ACC-002 网页跳转（REQ-002/004）

上传按钮打开 https://shtokendance.benlai.com 即满足跳转要求；详情定位到对应资源，未登录可完成网页登录并继续，URL 不包含客户端秘密。上传后刷新客户端可看到资源。

### ACC-003 指定范围检索（REQ-003/004）

用内容可区分的两个知识库验证：选择 A 的消息不检索 B；所选范围撤权或删除时不扩大；下一条未选消息恢复缺省行为。来源链接可核对。

### ACC-004 技能闭环（REQ-005/006/007）

网页上传、客户端刷新、手动安装、选用并发送任务全链路可复现；使用从未生成技能 release 的新目录条目验证，列表和安装不得调用发布接口或要求 published 状态。未点安装不安装，未发送不执行；坏包、重复点击、失败更新、同名技能及停用卸载均有定向验证。

### ACC-005 权限和兼容（REQ-008/009、NFR-001/004）

真实验证 60 秒撤权目标，保留身份隔离及 work-opc 既有功能回归证据；不能把断网、跳过或仅阅读源码写成通过。
